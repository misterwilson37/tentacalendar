🐙 Tentacalendar — Export / Backup

Reads a workspace and downloads it as JSON. Version 1.0.0

Read-only by construction. The Firestore write functions are not imported by this page, so it cannot modify anything even if it wanted to. Run it as often as you like — every run is a full snapshot and costs only reads.

1.x has exactly one workspace, primary (D12). Leave it alone unless you know otherwise.
